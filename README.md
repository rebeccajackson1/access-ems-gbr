# ACCESS-EMS-GBR

ACCESS-EMS-GBR is a regional atmosphere and ocean model of the Great Barrier Reef, comprising a regional configuration of the Australian Community Climate and Earth System Simulator (ACCESS) atmospheric model, coupled to the CSIRO Environmental Modelling Suite (EMS) hydrodynamic and biogeochemical marine model of the GBR.  


The model is intended to assess the implications of regional marine cloud brightening over the GBR, as part of the Reef Restoration and Adaptation Program (RRAP). 


A User Guide and scripts required to create input files and analyse the model outputs are provided here.
